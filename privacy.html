Privacy Policy

Effective date: September 5, 2026

This page describes the privacy position of the public KITC Digital Management System site. The public landing page is informational and does not require visitors to create an account.

Information handled by the public site

The public landing page does not intentionally collect personal information through forms. The management application may handle institutional records when an authorized user enters the protected workspace. Those records are governed by the application's access controls and the policies of the organization operating KITC.

Browser storage and device access

The Secretary workspace can use the browser File System Access API when an authorized user explicitly selects a KITC folder. The application uses that permission for its USB-backed record workflow. The browser and operating system control the underlying permission prompt.

Third-party services

The project may use GitHub Pages for public hosting and may integrate other services when configured. The project should not place secret credentials or service-role keys in public frontend files.

Security

Authentication and authorization should be enforced at the protected application and data layer. Hiding a button in the interface is not a security control.

Changes

This policy may be updated when the application's data practices change. The effective date identifies the current version.
